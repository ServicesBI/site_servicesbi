# ServicesBI — Site Oficial

Repositório oficial do site institucional da **ServicesBI**.

O projeto foi desenvolvido em Django como fonte principal, com exportação estática para publicação via Nginx no servidor de produção.

---

## Visão Geral

O site apresenta os serviços, projetos e soluções da ServicesBI nas áreas de:

- Engenharia de dados
- Automações com Python e n8n
- Dashboards em Power BI
- Excel avançado
- Portfólio de projetos
- Materiais técnicos e e-books
- Apresentação institucional e contato

---

## Stack Principal

- Python
- Django
- HTML
- CSS modular
- JavaScript
- Nginx
- GitHub
- Servidor OCI
- Cloudflare DNS
